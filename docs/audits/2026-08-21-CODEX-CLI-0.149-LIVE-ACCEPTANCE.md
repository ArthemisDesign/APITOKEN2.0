## Бюджетный факт

Оператор разрешил один paid turn с target `$0.0001`. Фактический Codex-composed system/tool context дал 14157 input
tokens. По current Luna official card это приблизительно `$0.00284` до discount и `$0.00142` при current 50% B2C
multiplier. Второй paid turn не запускался.

Это доказало, что внешний runner не может гарантировать hard pre-dispatch nanoUSD cap: он не знает итоговый system/tool
prompt, который Codex добавит до submission. Runner исправлен: flags описывают operator authorization target, а не
технически enforceable ceiling. Default остаётся без generation и без refresh-family rotation.
