ClaudeStore is a developer platform that provides instant access to Anthropic Claude AI models through a single API key. It supports Claude Opus 4.7, Opus 4.8, Sonnet 4.6, and Haiku 4.5 through API3. The API gateway is compatible with both the Anthropic Messages API and the OpenAI Chat Completions API. Developers can integrate with Cursor, Claude Code, VS Code extensions, and any SDK that supports a custom base URL. Billing is credit-based and discounted vs Anthropic — $45 buys $500 of Anthropic-equivalent usage and $90 buys $1,000. ClaudeStore accepts cryptocurrency payments including Bitcoin, Ethereum, USDT, and USDC. There is instant access and no Anthropic account is required. The platform also includes a referral program where creators, agencies, and dev communities can invite paying users and claim 10% rewards as Anthropic Usage or Solana USDT for Heleket-paid referrals.
