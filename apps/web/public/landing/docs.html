01 Быстрый старт

Подключите apiToken к coding agent.

Выберите стек — точная инструкция появится ниже. Ключ останется только в этой сессии терминала.

Claude Code · macOS / Linux · zsh · bash · Claude Opus 5
Endpointhttps://router.apitoken.sale

Выполните в терминале, из которого запустите Claude Code. Явный model flag не даст подхватить модель из старого логина.

unset ANTHROPIC_AUTH_TOKEN
export ANTHROPIC_BASE_URL="https://router.apitoken.sale"
export ANTHROPIC_API_KEY="sk-pool-•••"

claude --model claude-opus-5

В Claude Code/status должны быть apiToken.sale как Anthropic base URL и ANTHROPIC_API_KEY как источник ключа.

Anthropic Messages API · cURL
Endpointhttps://router.apitoken.sale

Держите ключ на сервере: переменная окружения или менеджер секретов, не браузерный bundle.

export APITOKEN_API_KEY="sk-pool-•••"

curl https://router.apitoken.sale/v1/messages \
  -H "x-api-key: $APITOKEN_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-opus-5",
    "max_tokens": 1024,
    "messages": [{"role": "user", "content": "Reply with exactly: connected"}]
  }'

02 Endpoint'ы

Один endpoint, все протоколы.

router.apitoken.sale — единая точка входа. Coding‑агенты и официальные SDK получают нативные API байт‑в‑байт; любой OpenAI‑совместимый клиент работает со всеми моделями каталога через один универсальный маршрут.

POST /v1/messages Anthropic
POST /v1/responses OpenAI
POST /v1beta/models/{model}:generateContent Gemini
POST /v1/chat/completions OpenAI‑совместимый
GET /v1/models Единый каталог

Per-provider endpoint'ы api.apitoken.sale, openai.api.apitoken.sale/v1 и gemini.api.apitoken.sale поддерживаются с тем же ключом и балансом — единый router рекомендован для новых интеграций.

04 Файлы в Gemini

Как отправлять файлы.

Gemini отдаётся из пула подписок, поэтому файл должен ехать внутри самого запроса. Отдельного шага загрузки нет: Files API недоступен.

Тип данныхПоддержкаКак отправлять
Изображения (PNG, JPEG, WebP)Даinline_data с mime_type и base64. До ~23 МБ исходного файла.
PDF-документыДаinline_data с application/pdf.
Текстовые файлыДаinline_data с text/plain или просто в text.
АудиоОдна модельТолько gemini-3-flash-preview, inline audio/wav.
Files API (file_uri)НетНедоступно. Передавайте содержимое inline.
cachedContentНетНедоступно. Передавайте содержимое inline.
 
{
  "contents": [
    {
      "role": "user",
      "parts": [
        { "text": "Describe this file" },
        { "inline_data": { "mime_type": "image/png", "data": "" } }
      ]
    }
  ]
}

Данные, которые шлюз принять не может, отклоняются ещё до обращения к подписке — 400 INVALID_ARGUMENT. В каждой ошибке есть заголовок x-request-id — назовите его поддержке.

05 Коды ответа

Основные коды ответа.

Каждый протокол сохраняет свой формат ошибок. Коды 401 и 402 требуют исправить состояние аккаунта; автоматически повторяйте только временные ошибки 429 и 5xx.

401 API-ключ отсутствует, неверен или отозван

Передайте активный ключ sk-pool в x-api-key. Повторять запрос с тем же отозванным ключом не нужно.

402 Недостаточно предоплаченного баланса

Пополните аккаунт, убедитесь, что баланс зачислен, и повторите запрос.

429 Лимит запросов или временный дефицит мощности

Учитывайте Retry-After; используйте ограниченную экспоненциальную задержку со случайным смещением.

5xx Временная ошибка шлюза или инфраструктуры

Повторите запрос с ограниченной экспоненциальной задержкой. Сохраните ID запроса.

06 Кеширование

Закешируйте префикс — платите 10% за чтение.

Claude — явный cache_control

Точки кеширования пробрасываются в Anthropic без изменений. Запись в кеш стоит 1,25× от цены ввода (TTL 5 минут) или 2× (TTL 1 час).

{
  "model": "claude-opus-4-8",
  "max_tokens": 1024,
  "system": [
    {
      "type": "text",
      "text": "Long stable instructions…",
      "cache_control": { "type": "ephemeral" }
    }
  ],
  "messages": [{ "role": "user", "content": "Short varying question" }]
}

GPT — автоматически

Ничего включать не нужно: повторяющиеся префиксы кешируются на стороне сервера. usage.prompt_tokens_details.cached_tokens тарифицируются как 10% от цены ввода.

{
  "usage": {
    "prompt_tokens": 5120,
    "prompt_tokens_details": { "cached_tokens": 4096 },
    "completion_tokens": 128
  }
}

Всё готово.Осталось подключить.

Начните с Claude Code или cURL — первый запрос займёт меньше минуты.
