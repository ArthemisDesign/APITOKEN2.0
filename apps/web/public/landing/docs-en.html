01 Quick start

Connect apiToken to your coding agent.

Pick a stack and the exact instructions appear below. The key stays only in this terminal session.

Claude Code · macOS / Linux · zsh · bash · Claude Opus 5
Endpointhttps://router.apitoken.sale

Run this in the terminal from which you launch Claude Code. An explicit model flag prevents picking up a model from an old login.

unset ANTHROPIC_AUTH_TOKEN
export ANTHROPIC_BASE_URL="https://router.apitoken.sale"
export ANTHROPIC_API_KEY="sk-pool-•••"

claude --model claude-opus-5

In Claude Code/status you should see apiToken.sale as the Anthropic base URL and ANTHROPIC_API_KEY as the key source.

Anthropic Messages API · cURL
Endpointhttps://router.apitoken.sale

Keep the key on the server: an environment variable or secrets manager, never a browser bundle.

export APITOKEN_API_KEY="sk-pool-•••"

curl https://router.apitoken.sale/v1/messages \
  -H "x-api-key: $APITOKEN_API_KEY" \
  -H "anthropic-version: 2023-06-01" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-opus-5",
    "max_tokens": 1024,
    "messages": [{"role": "user", "content": "Reply with exactly: connected"}]
  }'
OpenAI-compatible API · Python
Endpointhttps://router.apitoken.sale/v1/chat/completions
from openai import OpenAI

client = OpenAI(
    base_url="https://router.apitoken.sale/v1",
    api_key="sk-pool-•••"
)

res = client.chat.completions.create(
    model="claude-opus-5",
    messages=[{"role": "user", "content": "Hello"}]
)
print(res.choices[0].message.content)
02 Endpoints

One endpoint, all protocols.

router.apitoken.sale is the single entry point. Coding agents and official SDKs get native byte-for-byte APIs; any OpenAI-compatible client works with the whole catalog through one universal route.

POST /v1/messages Anthropic
POST /v1/responses OpenAI
POST /v1beta/models/{model}:generateContent Gemini
POST /v1/chat/completions OpenAI-compatible
GET /v1/models Unified catalog

Per-provider endpoints api.apitoken.sale, openai.api.apitoken.sale/v1 and gemini.api.apitoken.sale are still supported with the same key and balance — the unified router is recommended for new integrations.

04 Files in Gemini

How to send files.

Gemini is served from a pool of subscriptions, so the file must travel inside the request itself. There is no separate upload step: the Files API is not available.

Data typeSupportedHow to send
Images (PNG, JPEG, WebP)Yesinline_data with mime_type and base64. Up to ~23 MB source file.
PDF documentsYesinline_data with application/pdf.
Text filesYesinline_data with text/plain or just put it in text.
AudioOne modelOnly gemini-3-flash-preview, inline audio/wav.
Files API (file_uri)NoNot available. Pass contents inline.
cachedContentNoNot available. Pass contents inline.
 
{
  "contents": [
    {
      "role": "user",
      "parts": [
        { "text": "Describe this file" },
        { "inline_data": { "mime_type": "image/png", "data": "" } }
      ]
    }
  ]
}

Data the gateway cannot accept is rejected before reaching the subscription — 400 INVALID_ARGUMENT. Every error includes an x-request-id header; mention it to support.

05 Response codes

Common response codes.

Each protocol keeps its own error format. 401 and 402 require fixing account state; only retry temporary 429 and 5xx errors automatically.

401 API key missing, invalid or revoked

Pass an active sk-pool key in x-api-key. Do not retry with a revoked key.

402 Insufficient prepaid balance

Top up the account, confirm the balance is credited, then retry.

429 Rate limit or temporary provider capacity shortage

Respect Retry-After; use bounded exponential backoff with jitter.

5xx Temporary gateway or provider infrastructure error

Retry with bounded exponential backoff. Save the request ID.

06 Caching

Cache the prefix — pay 10% per read.

Claude — explicit cache_control

Cache points are passed through to Anthropic unchanged. Cache write costs 1.25× input price (TTL 5 min) or 2× (TTL 1 hour).

{
  "model": "claude-opus-4-8",
  "max_tokens": 1024,
  "system": [
    {
      "type": "text",
      "text": "Long stable instructions…",
      "cache_control": { "type": "ephemeral" }
    }
  ],
  "messages": [{ "role": "user", "content": "Short varying question" }]
}

GPT — automatic

Nothing to enable: repeated prefixes are cached server-side. usage.prompt_tokens_details.cached_tokens is billed at 10% of input price.

{
  "usage": {
    "prompt_tokens": 5120,
    "prompt_tokens_details": { "cached_tokens": 4096 },
    "completion_tokens": 128
  }
}
